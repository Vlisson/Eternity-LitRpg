# Fähigkeiten

> **Übersicht aller Skills und Zauber** im Eternity-Wiki.

## Typen
- **Passiv** - Aktiv automatisch, keine Ressourcen
- **Aktiv** - Manuell aktivierbar, hat Ressourcenkosten
- **Zauber** - Spezialisierte Magie, hat Cooldown
- **Talente** - Spezialisierungen innerhalb einer Klasse
