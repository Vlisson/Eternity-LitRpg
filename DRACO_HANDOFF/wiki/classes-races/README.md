# Klassen & Rassen

> **Übersicht des Klassen- und Rassensystems** im Eternity-Wiki.

## Rassen
- [[Mensch]] - Standard-Rasse, Startpunkt
- [[Drache]] - Legendäre Rasse, gottgleiche Macht
- [[Tiermenschen]] - Befreit durch globale Ereignisse
- [[Erzmagier]] - Legendäre Klasse (alternativ zur Drachenrasse)

## Klassen
- [[Amateur Schriftsteller]] - Startklasse (Ben)
- [[Drache/Dämonenlord]] - Klasse für Drachen-Rasse
- [[Erzmagier]] - Legendäre Klasse, Titel "Held der Menschheit"

## System
- **Start:** Mensch + Amateur Schriftsteller
- **Quest-Belohnung:** Wahl zwischen Drachenrasse oder Erzmagier-Klasse
- **Weitere:** Tiermenschen (nach globalen Ereignissen)
