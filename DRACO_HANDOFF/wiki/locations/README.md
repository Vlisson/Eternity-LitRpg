# Orte & Lokationen

> **Übersicht aller Orte** im Eternity-Wiki.

## Typen
- 🏙️ **Städte** - Siedlungen, Handelszentren
- 🏰 **Dungeons** - Gefährliche Gebiete
- 🌍 **Realms** - Großes Gebiet
- 🌌 **Welten** - Parallele Realitäten
- ⚔️ **Schlachtfelder** - PvP-/PvE-Gebiete
- 🏝️ **Inseln** - Abgesonderte Gebiete

## Aufzählung (Auswahl)
- [[Tropfsteinhöhle]] - Start-Dungeon, dunkle Höhle
- [[Reich der Dämonen]] - Versiegeltes Quest-Gebiet
- [[Essence-Nexus]] - Schimmernde Höhle mit Spiegel-Aura
- [[Stadt]] - Hauptstadt, Sitz der Konzerne
- [[Wald]] - Waldgebiet
- [[Vulkan]] - Aktives Vulkan-Gebiet

## Wichtige Regionen
- **Starter Städte der Menschen** - Sicherer Hafen für neue Spieler
- **Schattenwelt** - Parallel-Universum innerhalb von Eternity
- **Hauptstadt** - Sitz des schmierigen Daumens (Konzerne)
