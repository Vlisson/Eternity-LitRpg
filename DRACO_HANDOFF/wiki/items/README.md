# Items & Ausrüstung

> **Übersicht aller Gegenstände** im Eternity-Wiki.

## Kategorien
- ⚔️ **Waffen** - Nahkampf, Fernkampf, Magie
- 🛡️ **Rüstungen** - Kopf, Brust, Beine, Spezial
- 💎 **Artefakte** - Legendäre, einzigartige Items
- 🧪 **Consumables** - Tränke, Essen, temporäre Buffs
- 📦 **Sets** - Ausrüstungskombinationen mit Boni

## Aufzählung (Auswahl)
- [[Abenteuer-Paket]] - Startpaket (Fackel + Feuerstein)
- [[Fackel]] - Standardbeleuchtung
- [[Feuerstein]] - Feueranzündung
- [[Chitinpanzer]] - Mittlere Rüstung (aus Chitin)
- [[Goldene Kugel]] - Magisches Fokusobjekt
- [[Drachenhort]] - Schatzkiste des Drachen

## Seltenheitsstufen
1. **Gewöhnlich** (Common) - Häufig, geringe Werte
2. **Ungewöhnlich** (Uncommon) - Besser als gewöhnlich
3. **Selten** (Rare) - Wenig verbreitet, gute Werte
4. **Episch** (Epic) - Stark, besondere Effekte
5. **Legendär** (Legendary) - Sehr selten, mächtig
6. **Mythisch** (Mythic) - Einzigartig, spielverändernd
